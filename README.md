#O que é

E um programa desenvolvido para utilizar controles de PlayStation 4, incluindo modelos paralelos, como controles de Xbox 360 no Windows.

Ele converte os comandos do controle conectado por USB e conta com uma interface para testar botões, analógicos e gatilhos, além de permitir ajustes na zona morta.


#O que precisa para funcionar?

Windows 10 ou 11.

Controle de PS4 compatível, conectado por cabo USB de dados.

ViGEmBus: driver responsável por criar o controle virtual de Xbox 360.

HidHide: recomendado para evitar que os jogos reconheçam o controle físico e o virtual ao mesmo tempo.

Python: necessário apenas para executar o projeto pelo código-fonte, não pelo .exe.


#Como utilizar?

Execute instalar.bat para instalar as dependências e configurar os drivers necessários.

Abra o DS4Bridge.exe ou utilize Iniciar.bat.

Conecte o controle de PS4 e clique em Conectar.

Caso queira, ligue o HidHide, na primeira vez é necessario desconectar o controle e ligar novamente

Mantenha o programa aberto enquanto joga.
